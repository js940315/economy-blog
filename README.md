# economy-blog

네이버 경제 홈판용 콘텐츠를 매일 자동 생성하는 저장소입니다. 클라우드 예약 에이전트(Claude 스케줄링)가
매일 새벽 이 저장소를 체크아웃해서, RSS 뉴스를 읽고 `PROMPT_V1.md` 규칙대로 글을 쓰고, 차트 이미지를
만들어서 `output/{날짜}/{순번}/` 아래에 커밋합니다.

## 구조

- `PROMPT_V1.md` — 포스팅 생성 규칙 (제목·본문·가독성·해시태그 등 전체 스펙). **이 파일을 수정하면
  다음날 실행부터 바로 반영됩니다.**
- `common_utils.py` — 차트 SVG 생성 + PNG 변환 코드
- `state/seen_articles.json` — 최근 발행한 기사 기록 (중복 회피용, 에이전트가 매일 갱신)
- `output/{YYYY-MM-DD}/{1~10}/` — 매일 생성되는 결과물
  - `title.html` — 브라우저로 열어서 전체 복사, 네이버 붙여넣기
  - `meta.json` — 원본 데이터 (제목/카테고리/해시태그 등)
  - `chart.png` — 있으면, 마커(예: 【1번 이미지】) 위치에 드래그해서 넣기

## 매일 할 일 (사람)

1. `output/오늘날짜/1/` 부터 `10/` 까지 폴더 확인
2. 각 폴더의 `title.html` 열어서 전체 복사 → 네이버 블로그 붙여넣기
3. 마커(【N번 이미지】) 위치에 같은 폴더의 `chart.png` 드래그
4. 발행 버튼 클릭 (이 마지막 단계는 자동화 안 됩니다 — 네이버 로그인/발행은 사람이 직접)

## 참고

- 이미지 생성은 데이터 차트(막대그래프)만 자동입니다. 인물 일러스트 등은 이번 버전 범위 밖입니다.
- RSS 소스: 한국경제(economy/finance/realestate/international), 코인데스크코리아, 토큰포스트, 블록미디어
