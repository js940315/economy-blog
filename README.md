# economy-blog (경제 + 자동차 겸용)

네이버 홈판용 콘텐츠를 매일 자동 생성하는 저장소입니다. 클라우드 예약 에이전트(Claude 스케줄링) **2개**가
이 저장소 하나를 같이 씁니다 — 하나는 경제, 하나는 자동차. 서로 다른 파일 세트를 쓰기 때문에 안전하게 분리됩니다.

| | 경제 루틴 | 자동차 루틴 |
|---|---|---|
| 실행 시각 (한국시간) | 매일 06:00 | 매일 06:30 |
| 규칙 파일 | `PROMPT_V1.md` | `PROMPT_AUTO_V1.md` |
| 중복 방지 기록 | `state/seen_articles.json` | `state/seen_articles_auto.json` |
| 출력 폴더 | `output/{날짜}/{순번}/` | `output_auto/{날짜}/{순번}/` |
| RSS 소스 | 한국경제 4종, 코인데스크코리아, 토큰포스트, 블록미디어 | 모터그래프, 오토헤럴드, 모토야 |

`common_utils.py`(차트 생성 코드)는 둘이 공유합니다.

**규칙을 수정하고 싶으면** 해당 `PROMPT_*.md` 파일만 고쳐서 push하면 다음날 실행부터 바로 반영됩니다.

## 매일 할 일 (사람)

1. `output/오늘날짜/1~10/` (경제) + `output_auto/오늘날짜/1~10/` (자동차) 폴더 확인
2. 각 폴더의 `title.html` 열어서 전체 복사 → 네이버 블로그 붙여넣기
3. 마커(【N번 이미지】) 위치에 같은 폴더의 `chart.png` 드래그
4. 발행 버튼 클릭 (이 마지막 단계는 자동화 안 됩니다 — 네이버 로그인/발행은 사람이 직접)

## 참고

- 이미지 생성은 데이터 차트(막대그래프)만 자동입니다. 인물 일러스트 등은 이번 버전 범위 밖입니다.
- 자동차 루틴은 RSS 소스가 3개뿐이라 경제보다 하루 발행량이 적을 수 있습니다 (억지로 10개 안 채움).
- 새 주제를 또 추가하려면: `PROMPT_{주제}_V1.md` + `state/seen_articles_{주제}.json` + `output_{주제}/` 세트만 만들고, 클라우드 루틴 하나 더 예약하면 됩니다 (이 저장소 계속 재사용 가능).
