# 경제비버 — 매일 자동 생성 저장소

## 👉 매일 여기만 보시면 됩니다

**`output` 폴더** → 오늘 날짜(예: `0802`) → `1`, `2`, `3`... 번호 폴더

번호 폴더 하나 = 포스팅 하나입니다. 안에는 딱 5개만 있습니다:

```
0번 본문.txt      ← 복사해서 네이버에 붙여넣기
1번 사진.png      ← 【1번 사진】 자리에 넣기
2번 사진.png      ← 【2번 사진】 자리에 넣기
3번 사진.png
4번 사진.png
```

## 매일 작업 순서

1. `0번 본문.txt` 열기 → 전체 복사 → 네이버 블로그 에디터에 붙여넣기
2. 본문 안 `【1번 사진】` 자리에 → `1번 사진.png` 넣기 (우클릭 → 이미지 복사 → 에디터에서 Ctrl+V)
3. `【2번 사진】` → `2번 사진.png` … 순서대로
4. `【N번 사진】` 마커 글자는 지우기
5. 발행

파일명 번호와 본문 마커 번호가 똑같아서(`1번 사진` ↔ `【1번 사진】`) 헷갈릴 일이 없습니다.

## 나머지 폴더는 안 보셔도 됩니다

| 폴더 | 내용 |
|---|---|
| `_engine` | 자동화 코드·규칙 (건드릴 필요 없음) |
| `assets` | 로고·사진 재료 (자동으로 씀) |
| `state` | 중복 방지 기록 (자동으로 씀) |

궁금하실 때만 열어보시면 되고, **매일은 `output`만** 보시면 됩니다.
