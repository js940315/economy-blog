### 3-2. ✅ Google News RSS 키워드 피드 (권장 · 오늘 재검증 완료)

```
https://news.google.com/rss/search?q=<URL인코딩>&hl=ko&gl=KR&ceid=KR:ko
```
2026-08-04 `"연예인 다이어트"` 실행 결과 **100건 수집 성공**.
특정 인물·소재로 터지는 주제에는 고정 매체 피드보다 적중률이 훨씬 높다.

**취급 주의 3가지 (실측 확인 — 안 지키면 데이터가 더러워진다)**
1. `<title>` 끝에 `" - 매체명"` 이 붙는다 → 잘라내고, 매체명은 `<source>` 엘리먼트에서 따로 얻는다
2. `<link>` 는 news.google.com 리다이렉트 → 원문 URL이 필요하면 리다이렉트를 따라가야 한다
3. **날짜순이 아니라 관련도순이다** → 반드시 `pubDate` 로 정렬한 뒤 최근 N일로 필터링

동작 확인된 파싱 코드(그대로 써도 됨):
```python
import re, urllib.request, urllib.parse, email.utils
UA = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                    "(KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"}

def google_news(query, days=3):
    url = "https://news.google.com/rss/search?" + urllib.parse.urlencode(
        {"q": query, "hl": "ko", "gl": "KR", "ceid": "KR:ko"})
    raw = urllib.request.urlopen(
        urllib.request.Request(url, headers=UA), timeout=25).read().decode("utf-8", "ignore")
    out = []
    for it in re.findall(r"<item>(.*?)</item>", raw, re.S):
        t = re.search(r"<title>(.*?)</title>", it, re.S)
        d = re.search(r"<pubDate>(.*?)</pubDate>", it, re.S)
        s = re.search(r"<source[^>]*>(.*?)</source>", it, re.S)
        if not (t and d):
            continue
        out.append({
            "title": re.sub(r"\s+-\s+[^-]+$", "", t.group(1)).strip(),   # 주의 1
            "date": email.utils.parsedate_to_datetime(d.group(1)),
            "source": s.group(1) if s else "",
        })
    out.sort(key=lambda r: -r["date"].timestamp())                        # 주의 3
    return out[:40]
```

**추천 쿼리 세트** (하나로 뭉치지 말고 여러 개를 돌려 합친 뒤 중복 제거)
`연예인 다이어트` / `아이돌 식단` / `배우 체중감량` / `다이어트 성공 비결` /
`감량 후 근황` / `다이어트 부작용` / `위고비 삭센다` / `홈트 운동법`

## 5. 본문 파이프라인 (그대로 재사용)

**빌드는 반드시 저장소 루트에서:**
```bash
python _engine/build_posts.py _engine/articles_today.json 0804
```
→ `output/0804/{순번}/0번 본문.txt` + 루트에 `build_report.json`
→ **`problems` 가 빈 배열이어야 정상.** 남아 있으면 그 기사만 고쳐 다시 빌드한다.

**기사 JSON 스키마 (이미지 제외 버전 — 이대로 쓰면 된다)**
```jsonc
{
  "title": "제목",
  "category": "다이어트 카테고리",
  "images": [],                    // ← 이미지 방식 정해지기 전까지 빈 배열
  "intro": ["3문장 이내"],
  "body_paragraphs": [             // ⭐ '문장 하나'가 배열 원소 하나
    "📌 소제목",                    //   빌더가 밑에 구분선을 자동으로 깐다
    "문장.", "문장.",
    "💡 핵심 한 입"
  ],
  "editor_comment": ["편집자 관점 2~3문장"],
  "closing_question": "여운형 질문 (⛔ '댓글' 단어 금지)",
  "disclaimer": "8절 참고 — 건강용으로 교체",
  "hashtags": ["#다이어트", "#..."]
}
```

**빌더가 강제로 보정해 주는 것** (에이전트가 신경 안 써도 됨)
- 마크다운 기호(`**`, `##`, `` ` ``) 제거 — 네이버에 그대로 노출되면 AI 티가 난다
- 문단 사이 점자 공백 `⠀⠀⠀` 삽입 (네이버 붙여넣기에서 살아남는 유일한 간격)
- 문단이 110자를 넘으면 **문장 경계에서만** 분리

**네이버 절대 규칙**
- ⛔ 마크다운·볼드 금지 (에디터가 해석 못 하고 별표가 그대로 보인다)
- ⛔ **문장 중간 줄바꿈 금지** — 네이버가 화면 폭에 맞춰 알아서 감싼다
- ⛔ '댓글' 이라는 단어 자체 금지 (구걸처럼 보여 역효과). 대신 맨 끝 여운형 질문
- 소제목 `📌 `, 핵심/관점 `💡 ` — 글당 이모지 장치 총 3~5개 이내

## 9. 공통 함정 (실측으로 확정된 것)

- **RSS 403은 흔하다.** 한국경제 등도 브라우저 UA 없이는 403. UA를 반드시 붙인다.
- **Wikimedia 429는 rate limit이 아니라 User-Agent 정책 위반인 경우가 많다.**
  제품명+버전+**연락처 URL**이 없는 UA는 429로 막히는데 문구 때문에 오진하기 딱 좋다.
  몇 시간 기다려도 안 풀리고 UA만 고치면 즉시 통과한다.
- **Pexels 403은 키 문제가 아니다.** Cloudflare가 봇 UA를 error 1010으로 막는다 → 브라우저 UA 필요.
- **커밋 메시지에 단독 `/` 를 넣지 말 것.** Git Bash(MSYS)가 이를 윈도우 경로로 변환해
  `'C:/Program Files/Git/' is outside repository` 로 커밋이 실패한다.
  여러 줄 메시지는 `git commit -F -` + heredoc 으로 넘긴다.
- **상태 JSON은 원자적으로 쓴다**(tmp → `os.replace` → fsync). OneDrive·비정상 종료로
  `seen_articles.json` 이 0바이트/NUL로 깨진 사례가 있다. 읽을 때도 손상 시 기본값으로 복구.
- **로컬 PC 불안정**: 무거운 빌드가 커널 크래시(MEMORY_MANAGEMENT 블루스크린)의 방아쇠가 된 적 있다.
  대량 작업은 나눠서 돌리고, 렌더를 쓰게 되면 `RENDER_CONCURRENCY=1~2` 로 낮춘다.
- **다른 주제 저장소는 건드리지 않는다.** 주제별로 **세션도 분리**한다
  (같은 파일을 두 세션이 동시에 고치면 충돌·덮어쓰기 사고가 난다).
